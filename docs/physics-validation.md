# Native physics validation (development branch)
The existing grid-based experiments remain unchanged. This first milestone constructs the same rack layout and seeded start positions as the grid simulation, with one metre per cell, free-base 10 kg robots, two independently actuated wheels, low-friction support spheres approximating casters, planar ground and physical rack contacts. Parameters are provisional, not hardware-calibrated. Static obstacles only in this first smoke test. The simulator does not send Flagsmith events.

Install with python -m pip install -r requirements-physics.txt. Run python -m roboflag.physics --smoke and python -m pytest -q tests/test_physics.py. CI runs the native engine headlessly and archives the measured forward and braking displacement. The smoke test checks motion, finite state, lateral drift and external contact pairs. It is not a navigation experiment.

Next gate: closed-loop heading and waypoint tracking; then paired multi-robot scheduling with both existing planners on fresh seeds. Report physical contact episodes, not per-step contact counts, and distinguish grid time from physics time. Dynamic obstacle behavior, robustness sweeps and actual hardware validation remain out of scope for this first commit. Do not merge or claim physics performance until tests run.

## First observed failure
Run 45492670704: native model compiled; commanded 0.35 m/s for one second yielded 0.0358701 m, below the unchanged 0.10 m acceptance floor. Lateral drift 0.0000503 m, braking displacement 0.0001071 m, zero external contacts. Hypothesis: equal-priority ground and caster friction mixing gives the nominally low-friction support the floor friction. Explicit tire/caster geom priority isolates their intended friction; add wheel velocity, actuator force and effective contact friction diagnostics. This is a hypothesis under test, not a confirmed fix. Preserve smoke artifact on failure.

## Corrected smoke and tracking gate
Run 45492807410 passed both smoke tests: displacement 0.3256653 m, drift 0.0019556 m, braking 0.0150712 m, zero external contact pairs. Effective caster/tire friction 0.005/1.2. Next development test uses a 1 m cardinal square at seed 4000, common closed-loop heading gate, proportional velocity, 50 mm settling tolerance, 12 s timeout per waypoint, native contact episodes and absolute actuator mechanical work proxy. This is a development scenario, not a holdout or hardware energy measurement. No native experiment traffic. Run python -m roboflag.physics_tracking for trace and results.

## Paired development fleet benchmark
Run 45492947905 passed the native square tracking gate. The next benchmark uses six robots, paired seeds 4100–4102, static racks, 100 reservation rounds, the unchanged A* planners and identical wheel tracking. Each round holds reservations until every robot settles within tolerance; any timeout terminates the fleet and is reported. Physical contact episodes, blocked proposals, mission completion seconds, mechanical work proxy and sampled poses are recorded. This synchronous barrier is conservative and is not a realistic asynchronous industrial scheduler. Dynamic obstacles are deliberately excluded pending safe insertion modeling. These are development seeds, not independent holdout evidence; no Flagsmith traffic and no assumed transfer of grid results.
